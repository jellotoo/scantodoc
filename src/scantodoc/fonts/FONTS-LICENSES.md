# Bundled fonts

These fonts ship with ScanToDoc so that HTML and PDF exports look right even on
a computer that does not have them installed. All of them are licensed under
the SIL Open Font License 1.1 (full text in `OFL.txt`), which allows bundling
and redistribution.
